# Vendor Versions

The upstream packages this module tracks, and where each one stands. The rules are in
[CLAUDE.md](CLAUDE.md#upstream-watch).

- **Reviewed:** the version our open issues and the register were last checked against. A
  [version review](CLAUDE.md#vendor-updates-version-reviews) sets it when it finishes.
- **Latest published:** the newest version the vendor has published. The daily upstream watch
  (`node tools/upstream-watch.mjs`) writes it, and the date it first saw that version.

When **Latest published** is newer than **Reviewed**, the package needs a version review.
